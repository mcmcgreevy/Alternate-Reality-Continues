# Kroah — The City, Atari ST v2.0

Archived 2026-11-16 from [Kroah's reverse-engineering site](http://bringerp.free.fr/RE/Ar/news.php5). Author: Kroah. The source explicitly identifies the Atari ST v2.0 edition and warns of differences from 8-bit City.

Each `.html` is the unchanged HTTP response; its adjacent UTF-8 `.txt` is a convenience extraction. Text extraction flattens tables and cannot preserve palette diagrams or image-only information. Consult the original HTML/table structure when extracting rules. The [City map image](Map.png) was additionally archived on 2026-11-16 to verify markers 16 and 49. Other external images, audio, CSS, scripts and downloads have **not** been archived, and relative links in raw snapshots are not rewritten for offline navigation. This is a document snapshot collection, not a complete offline mirror.
