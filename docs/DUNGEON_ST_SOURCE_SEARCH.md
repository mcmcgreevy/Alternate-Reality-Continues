# Atari ST Dungeon source search

Researched 2026-11-21. No public ST Dungeon disassembly, verified executable or Kroah-style rules breakdown was located. This is a search result, not proof that no private prototype survives.

## Release evidence

- [AtariMania ST Dungeon record](https://www.atarimania.com/games/atari-st-games-alternate-reality-the-dungeon-40260) classifies the title and its dump as unreleased and notes advertising in ST Amiga Format issue 2.
- [ST/Amiga Format issue 2 advertisement](https://www.stformat.com/staf02/staf02.pdf) claims ST availability. Advertising establishes a marketing claim, not a verified shipped executable; retain this discrepancy.
- [Current Notes, October 1988](https://www.atarimania.com/mags/pdf/Current_Notes_Volume_8_Number_8_Oct_1988.pdf) reports the ST Dungeon would not appear before 1990. This contemporary report supports delay, not a subsequent release.

## Reusable research leads

- Existing pinned `ardungeon` remains our direct Atari 8-bit Dungeon implementation evidence; see DUNGEON_LEVEL_ONE.md and RECONSTRUCTION.md.
- [CRPGDev links](https://www.crpgdev.com/links.html) identifies Jim Norris's Alternate Reality Disassembly Project as a source of City/Dungeon tools and information. This search did not recover or validate its underlying technical collection.
- [Land Beyond's first-person remake description](https://forums.atariage.com/topic/379316-alternate-reality-the-remake/) reports disassembling City/Dungeon and combining Dungeon gameplay with ST City guild behavior. It is a useful research lead, not evidence of an ST Dungeon release or an independently verified formula collection. No contact was made and no implementation was imported.

## Project consequence

Retain Kroah ST City v2.0 for City and verified Atari 8-bit Dungeon for Dungeon. For shared systems, recover Dungeon formulas from existing disassembly and compare explicit inputs/outputs with City behavior. Document cross-chapter conversions as remake decisions. There is currently no verified ST Dungeon ruleset to use as an automatic bridge.

## Preservation limitation

Web search/read results were reviewed. Direct archival requests for AtariMania, CRPGDev and AtariAge failed with DNS errors in the local environment. No unchanged local snapshots were obtained; the magazine PDFs were located through indexed text but not downloaded or visually verified. All five URLs are recorded in the documentation catalog with this limitation. This file is analysis, not a source snapshot.
